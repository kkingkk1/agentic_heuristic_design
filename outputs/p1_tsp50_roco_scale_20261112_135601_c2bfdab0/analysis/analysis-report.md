# TSP50 对照分析

## 问题与口径

比较本方法和 RoCo 适配在 TSP50 白盒任务上的最终路线长度。每法三次独立研发，每次冻结一个候选并测试相同 64 个实例。路线长度越低越好；独立统计单位是研发运行，标准差为样本标准差。

## 质量

- 本方法逐次均值：5.820370、5.810071、5.833407；总体为 5.821282 ± 0.011695。
- RoCo 逐次均值：5.809879、5.808323、5.797632；总体为 5.805278 ± 0.006667。
- 本方法减 RoCo 为 +0.016004，相对 RoCo 为 +0.276%。本批次观察到 RoCo 的平均路线更短；这不是显著性或普遍优越性结论。
- 按相同研发种子编号逐次相减，差值为 +0.010490、+0.001748、+0.035774；第三次差值占三次差值总和的约 74.5%。这只是描述，不能把相同编号视为共享初始种群的配对实验。

### 训练筛选与测试排序

第三次研发的最终候选在同一组 5 个训练实例、每实例 200 次迭代下，本方法的平均路线为 5.780449，RoCo 为 5.786272；在同一组 64 个测试实例、每实例 500 次迭代下，分别为 5.833407 和 5.797632，排序反转。测试集中，本方法在 18 个实例更好、RoCo 在 42 个实例更好、4 个实例相同；实例数不是独立研发重复数。

训练差异受个别实例影响：第三个训练实例上本方法的路线短约 0.1253，其余四个实例的平均路线反而长约 0.0240。5 个实例的筛选对单个实例表现较敏感。训练与测试同时改变了实例、随机种子和迭代次数，因此这些记录不能单独证明过拟合，也不能区分各因素的作用。

训练记录见[本方法第三次冻结清单](../../p1_frozen_candidates/proposed_solution_quality_and_speed_agents/20261113_182734_19e8e233_resume/manifest.json)和 [RoCo 第三次冻结清单](../../p1_frozen_candidates/roco_paper_adapted/20261113_223251_4e4a7f6f_resume/manifest.json)；测试结果分别见[本方法](../../p1_test/proposed_solution_quality_and_speed_agents/20261114_002938_b4d6ed89/result.json)与 [RoCo](../../p1_test/roco_paper_adapted/20261114_101742_0bd83178/result.json)。

## 耗时与开销

- 本方法三次平均单实例求解时间：8.338542、8.319006、8.311718 秒，运行均值 8.323 秒。
- RoCo 三次平均单实例求解时间：4.754759、3.989074、3.895884 秒，运行均值 4.213 秒。测试时段和休眠中断构成明显混杂，不能据此宣称速度优势。
- RoCo 首组休眠前 14 个实例平均 7.890 秒，唤醒后其余 50 个实例平均 3.877 秒。两段实例不同，不能仅凭这一差异确定原因。
- 对同一批前 14 个实例，本方法三个候选在休眠前分别为 7.911、7.890、7.885 秒，平均 7.895 秒；RoCo 首组在休眠前为 7.890 秒，RoCo 第二、三组在唤醒后分别为 4.175、3.870 秒。候选并不相同，不能据此确定休眠或具体系统状态的因果作用；记录也没有足够的历史 CPU 频率和负载数据。
- 每次求解只直接调用一次启发式函数，再运行固定的 500 次 ACO 迭代。本方法与 RoCo 的函数自身平均耗时分别约为 0.879 毫秒和 1.019 毫秒，其直接耗时无法解释完整求解时间相差约 4.110 秒；启发式数值仍可能影响求解过程。
- 本批使用质量设置，候选按训练集路线质量筛选，不按耗时筛选。速度角色会收到计时反馈，但固定 500 次迭代并不会因提前收敛自动结束。训练评价最高并发为 4，单次计时可能受并发及环境影响；现有记录不足以证明速度反馈导致质量下降。
- 本方法共 1260 次模型调用、1113 次训练评价；RoCo 共 1257 次调用、1088 次评价。失败及其开销保留。
- 训练评价子进程 CPU 时间合计：本方法 12522.25 秒，RoCo 11848.69 秒；不含模型调用进程。
- 六个冻结候选均通过 64 个测试实例的路径与目标核验，共 384 条有效结果。研发阶段的候选错误与基础设施中断分别列于数据表。
