## 候选记录读取

[归档工具](prepare_candidate_archive.py)只核验、读取和恢复候选；工具没有删除功能。在项目根目录运行：

```powershell
python -B outputs/p1_tsp50_roco_scale_20261112_135601_c2bfdab0/compact_20261116/prepare_candidate_archive.py archive-check
```

该命令不依赖原候选文件，检查归档整体哈希、索引和全部候选内容。

需要恢复某个候选时，提供其原始项目相对目录。例如：

```powershell
python -B outputs/p1_tsp50_roco_scale_20261112_135601_c2bfdab0/compact_20261116/prepare_candidate_archive.py restore-candidate outputs/p1_control/20261113_182734_19e8e233_resume/candidates/c0333
```

恢复入口校验归档哈希，不覆盖内容不同的现有文件。命令的现有文件分支和缺失文件的内存模拟已验证；本次未删除候选原文件，因此未在实际删除后的候选目录上执行恢复。若以后经确认移除候选原文件，旧续跑脚本动态读取时需要先恢复所需候选。
